Security checklist

  • Only your verified email can write to the database (enforced in firestore.rules).
  • Anyone can send you a message, but only with valid, size-limited fields. Nobody but you can read them.
  • All content is escaped before display, so stored text can't inject scripts into your site.
  • Strict Content-Security-Policy and security headers are set in firebase.json.
  • In the Firebase console → Authentication → Settings, turn off "Enable create (sign-up)" so no one else can register accounts.
  • Use a long, unique password and turn on 2-step verification on your Google account.
